# Project ticket triage

## Customer selects a project

As a customer, I can select an active WiseWork project linked to my organization when opening a request. The server verifies the project belongs to my organization. General requests remain available for tickets without a project.

As a Right Tracker administrator, I link the organization to its WiseWork client record in **Organizations**. The portal only lists that client's projects.

## Project head reviews incoming work

As a project head, I can find unassigned tickets for my projects in a dedicated Right Tracker queue and receive an email when a new request arrives. Email delivery is independent of ticket creation. Tickets with no configured head remain available in the general staff queue.

## Project head assigns an employee

As a project head, I can assign a ticket for my project to an active project member with a staff account. The server validates the actor and assignee on both single and bulk changes. Administrators can triage in the head's absence and route tickets to the correct project.

## Employee sees the assignment

As an assigned employee, I receive the WiseWork assignment notification and can open the synchronized ticket in My Tickets. A project head's triage role does not make them the assigned employee.
